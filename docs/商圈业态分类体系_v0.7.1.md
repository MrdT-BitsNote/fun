# 商圈业态分类体系 v0.7.1（修订版）

> 本文档记录数据层的业态分类口径。v0.7.1 的核心变更是把「成人娱乐」
> 正名为「**休闲娱乐**」并扩展语义，同时把成人向游乐场从儿童类分流。
> 所有判据均可复算，不引入主观判断。

## 1. 为什么改名

「成人娱乐」在中文语境有三重问题：

1. **歧义**：日常口语中该词常指向夜色/情色业态，而数据层实际收录的是
   KTV、电影院、棋牌、密室等大众休闲项目——名词与内容错位。
2. **不完整**：原名覆盖不了体育馆、足疗按摩、卡丁车、水上乐园、
   桌游、蹦床等正当休闲消费，这些项目此前被挤进「其他娱乐场所」。
3. **不利于检索**：用户在数据层/网站上找「能带孩子去哪玩」「哪里足疗」
   时，不会联想到「成人娱乐」这个词。

改名后语义边界清晰：**休闲娱乐 = 工作之余的付费休闲消费场所**，
与「儿童亲子」（按客群分）、「美食」（按消费目的分）正交。

## 3. 三条分流规则（防串类）

### 3.1 儿童向优先规则
名称或地址命中 `儿童 / 亲子 / 淘气堡 / 迷你 / 孕婴童 / 婴童 / 少儿`
→ 归**儿童亲子**（§4），即使名称含「游乐场」。

示例：「彩虹岛亲子乐园」→ §4；「超级乐市(super fun space)」→ §3。

### 3.2 餐饮护栏规则
名称命中强餐饮词（菜/餐厅/饭/海鲜/河鲜/火锅/烧烤/酒楼/小吃/粥/烤鱼/
龙虾/鸡/鸭/鱼等）且不含任何娱乐词（吧/CLUB/酒/咖/KTV/影/玩/乐）
→ 判定为餐饮店，**不进休闲娱乐**。

背景：高德会给餐酒吧、园区餐厅打混合 type。v0.7.1 实测
「网网有鱼特色河鲜(岳阳楼店)」type = `体育休闲服务;娱乐场所;酒吧/
餐饮服务;餐饮相关场所;餐饮相关`，实为餐厅，曾误入休闲娱乐 386 家名单。

### 3.3 子类统计带 type 字段
§3 子类统计与逐行渲染的判定文本 = **名称 + 地址 + 高德 type 三段拼接**。
只取名称会漏掉大量店铺——「十二兽(润华时代中心店)」名称无「酒吧」，
但其 type 为 `体育休闲服务;娱乐场所;酒吧`，必须靠 type 归入酒吧类。

## 3bis. 商圈载体判定（v0.7.1 修复，与上三条同级重要）

v0.7.1 实测发现 §2 商圈档案混入门店，三重修正：

### 3bis.1 剥离分店后缀
「盛香亭转转热卤(岳阳步行街店)」→「盛香亭转转热卤」再判定。
名称里的「(XX步行街店)」是分店位置，不是门店性质。
`strip_branch()` 循环剥离尾部括号段。

### 3bis.2 地址不参与载体判定
「酒蜗KTV(岳阳北辅街店)」地址含「哇噻百货」被 `is_mall` 误判为商场。
地址里的「XX路/百货」是门店位置，不是门店性质。

### 3bis.3 类型码护栏
只有类型码为 **06 购物服务类**（060100 商场/060101 购物中心/060102
普通商场/061000 特色商业街/061001 步行街…）或 **050000 餐饮相关场所**
（高德把美食街/夜市归在此类，如「炮台山夜市」tc=050000）才算载体。

050100+ 是具体餐厅（中餐厅/湘菜/火锅…），**永远不是载体**。

实测误判案例（修复前全部混入岳阳 §2）：
- 「细毛私房菜(湘都巷店)」tc=050100 —— 关键词"小吃街"查询面夹带
- 「巴陵玖号老街菜馆」tc=050100 —— 名称含"老街"命中 STREET_CTX
- 「酒蜗KTV(岳阳北辅街店)」tc=080301 —— 地址含"百货"命中 is_mall
- 「NB2 DANCE CLUB(百盛广场旗舰店)」tc=080304 —— 分店后缀未剥离

修复后岳阳 §2 载体构成（184 处）：购物中心/综合体 59 · 百货/商场 41 ·
步行街 20 · 商业街 18 · 批发城 15 · 其他商业载体 12 · 夜市 10 ·
美食街/小吃街 9——零门店混入。
