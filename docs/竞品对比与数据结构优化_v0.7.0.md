# 同类产品横向对比与数据结构优化（v0.7.0）

> 对标目的：不是抄功能，而是把别人被验证过的数据组织方式吸收进本库 schema。
> 调研时间：2026-10-23  ·  对应版本：本地美食探索 skill v0.7.0 数据层

---

## 1. 同类产品对比

| 产品 | 数据组织方式 | 评级体系 | 优点（可吸收） | 短板（我们的机会） |
|---|---|---|---|---|
| **大众点评必吃榜** | 按城市→榜单→商户三层；每年一期，动态下榜 | 五维模型：评价真实可信 / 口味优中选优 / 长期稳定体验佳 / 符合日常消费水平 / 满足日常就餐选择 | ① 维度化评选，每个维度可解释；② 本地用户评价占比 >70% 过滤游客店；③ 收录满 365 天 + 营业 ≥182 天的稳定性门槛；④ 动态下榜，不是终身制 | 只有餐饮、只有榜单城市、无商圈结构、无坐标/动线、UGC 依赖平台生态 |
| **高德/百度地图 POI** | 21 主类 / 193 子类分类码 + POI 全字段（坐标/评分/人均/图片/营业时间） | 单字段评分（0–5） | ① 分类码驱动，不靠名称猜；② 字段全、可机器处理；③ 覆盖全国所有地市 | 无「商圈」概念（只有单个 POI）、无关联、无榜单/画像、评分来源单一 |
| **开源全国商圈数据集**（GitHub: BusinessDistrict 等） | 省/市/商圈名/经纬度 一张表 | 无 | 轻量、可整包下载 | 只有名称+坐标，无评级、无业态构成、无美食关联，用户查了还得自己跑一趟 |
| **全球开源 POI 集**（Iter-X/open-poi-datasets 等） | 按大洲/国家/城市分层，POI 带分类+坐标+多语言名 | 无 | 结构化字段、多语言、机读友好 | 无中文商圈语义、无餐饮细分、无口碑数据 |
| **马蜂窝/携程城市攻略** | 景点/美食/购物/住宿/交通 + 榜单 + 用户游记 | 编辑精选 + 用户点赞 | 内容结构完整、旅行动线友好 | 人工生产、覆盖有限、不可机读、更新慢 |
| **米其林指南** | 城市→餐厅→星级 | 专家评审团星级 | 权威性强、标准严格 | 评审团小众、脱离日常消费、无本地烟火气覆盖 |

## 2. 吸收的优点 → v0.7.0 落地改造

| # | 吸收点（来源） | 我们的落地 |
|---|---|---|
| 1 | 五维评选、判据可解释（必吃榜） | POI 五级标记 ✅A/✅A-/✅B/⚠️/❌ 每条带判据文字；**商圈级新增 S/A/B/C 评级**，量化门槛写进 md 表头，可复算 |
| 2 | 维度化而非单一人气分（必吃榜） | 商圈评级看四个维度：关联美食数、美食均分、业态覆盖类数、酒店配套，任一维度不达标即降级 |
| 3 | 分类码驱动（高德 POI 体系） | 全库按 typecode 分类（0501xx 餐饮 / 0601xx 购物 / 0803xx 夜生活 / 100000 住宿…），名称语义只做兜底 |
| 4 | 商圈不能只有名称+坐标（开源数据集短板） | 每商圈一节档案：载体类型、消费带宽（人均中位数+区间）、动线主轴（地址道路词频）、业态分布表、代表店 |
| 5 | 可推导 vs 不可推导要分清（必吃榜「本地评价占比」我们没有 UGC） | 画像分两类：可推导的直接给；不可推导的（高峰时段/本地客成分/可跳过商业段）显式标「待人工校对」，不编造 |
| 6 | 机读优先（开源 POI 集） | `data/_status.tsv` + `site/data.json` 双机读出口；原始 JSON 全字段落盘可回查 |
| 7 | 稳定性门槛（必吃榜收录 365 天） | 高德无收录时长字段，用替代信号：老字号关键词 + 营业时间字段 + 多查询面重复命中（一个 POI 被 3+ 个查询面命中说明收录稳定） |
| 8 | 动态更新而非一锤定音（必吃榜动态下榜） | 全链路可重跑：采集（断点续传/波次补采）→ 渲染 → 校验 → 索引 → 网站，一轮命令全量刷新 |

## 3. v0.7.0 数据结构总览

### 3.1 目录结构

```
local-food-explorer/
├── SKILL.md                          # skill 主文档（v0.7.0 数据层说明）
├── data/                             # ← 数据层（可整包发布）
│   ├── README.md                     # 全国总索引（进度/维度定义/校对入口/纪律）
│   ├── 行政层级总览.md               # 省→市→区县→镇街 全量层级（43,474 节点）
│   ├── _status.tsv                   # 机读进度表

│   ├── amap_collect.py               # 采集器（多 key 池/波次/限速/预算硬闸）
│   ├── render_md.py                  # 渲染器（md v0.7.0 结构）
│   ├── build_index.py                # 索引生成器
│   ├── validate_data.py              # 校验器（10 项规则）
│   ├── build_hierarchy.py            # 行政层级构建器
│   ├── fetch_district_tree.py        # 行政区划树采集器

├── docs/
```

## 5. 已知边界（如实声明）

- **无 UGC**：评分只有高德单一口径，无法像必吃榜那样过滤游客店/识别刷分；
  「本地客成分」一律标待人工校对。
- **无营业状态**：高德不返回是否在营，撤柜风险靠校对待办提示。
- **收录偏置**：高德 POI 对大店/连锁收录全，对小摊/无证小店收录少——
  苍蝇馆与无 POI 传统小吃必须靠人工补充（skill 侧已有小吃档流程）。
- **村级缺失**：高德行政区划不下探到村。
- **台湾 POI 覆盖**：高德对台湾的 POI 收录有限，建库以大陆城市为主。
- **港澳 POI**：香港早期探测 5/5 锚点解析失败，建库时以实际返回为准。
