数据接口文档

全国数据整合为两个全量文件——一次请求拿全量，不必逐城拼凑。所有端点只读、无鉴权、可被 CDN 缓存，适合 skill / agent / 前端直接消费。

城市记录字段（cities[]）

字段类型说明
city / province / adcodestr城市名 / 所属省 / 高德区划代码（页面文件名同 adcode）
poi_total / district_countint去重 POI 总数 / 商圈档案数
waves / updatedarray / str采集波次（1 美食商圈 / 2 酒店亲子商场 / 3 休闲全维度）/ 采集时间
credibilityobj§0 可信度：poi_total / rated_ratio / warnings / dims 六维计数
overviewobj§1 总览：行政层级 / 各区县 POI 分布 / 载体类型分布
districtsarray§2 商圈档案：name / grade(S·A·B·C) / carrier / rating / food / leisure / kids / hotel / detail
gradesobj本市商圈评级计数 {S, A, B, C}
food / xiaocanarray§6 美食 / §7 小店候选（POI 记录，字段见下）
leisure / kidsobj§3 / §4：{"subcats": [{name, count}], "list": [POI]}
malls / specialties / hotelsarray§5 综合体商场 / §8 特产 / §10 酒店

queries / externalarray / obj§11 原始查询面统计 / 美团·大众点评城市外链
pagestr城市页相对地址 cities/<adcode>.html

POI 记录字段（各明细表内）

字段类型说明
markstr商圈携带标记，如 ✅A-；空 = 不属任何已评商圈
namestr店名 / 名称

调用示例

# 1. 全量一次落地（约 51.3 MB，CDN 自动 gzip/br）
curl -s https://fun.worldstip.com/data.json -o fun-data.json

# 2. Python 流式读取，只保留目标城市
import json, urllib.request
with urllib.request.urlopen("https://fun.worldstip.com/data.json") as r:
    d = json.load(r)
yy = next(c for c in d["cities"] if c["city"] == "岳阳市")
print(yy["poi_total"], yy["grades"], len(yy["food"]))

# 3. 只要某省汇总 / 某城商圈 S 级
curl -s https://fun.worldstip.com/data.json | jq '.provinces[] | select(.province=="湖南省")'
curl -s https://fun.worldstip.com/data.json | jq '.cities[] | select(.city=="岳阳市") | .districts[] | select(.grade=="S")'

# 4. 全国美食榜前 10（评分降序，已剔住宿业主导 POI）
curl -s https://fun.worldstip.com/data.json | jq '.food_top[:10]'

# 5. 带图美食（jq 过滤 img 非空）
curl -s https://fun.worldstip.com/data.json | jq '[.cities[] | select(.city=="岳阳市") | .food[] | select(.img != "")][:10]'

# 6. 人类可读全量 Markdown（LLM / skill 直读）
curl -s https://fun.worldstip.com/data.md -o fun-data.md

使用约定

一致性承诺：data.json 与 data.md 由同一数据层（build_api.py）从 data/ 源档案一次生成，同源同值；任一字段都能在 data.md 对应城市档案中找到出处。
  • 无鉴权无限率：静态托管 + CDN 缓存，请合理使用（建议客户端侧缓存 24h）。
  • 评分口径：高德快照评分（0–5），采集时间见各城市 updated 字段；人均单位元。
  • 标记口径：✅ 优质 / ⚠️ 待核 / ❌ 不推荐；派生规则见各城市页说明。
  • 美食榜口径：已剔除名称命中酒店/宾馆/旅馆/民宿/客栈/客舍等关键词、或主类型段为住宿服务的 POI。
  • 变更频率：数据层随采集波次滚动更新，全量文件整体刷新；大版本变更在 GitHub Releases 说明。
  • 许可：数据仅可正当使用，不得整库转售；请保留来源标注（高德/美团/大众点评）。
