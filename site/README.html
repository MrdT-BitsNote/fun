部署与备份说明

FUN 站点为纯静态零依赖产物，任意静态托管均可运行。

站点结构

site/
├── index.html              # FUN hero + 主站
├── assets/                 # style.css / app.js（零依赖）
├── cities/<adcode>.html   # 城市页
├── provinces/<省>.html    # 省份页
├── api.html                # 数据接口文档
├── sources.html            # 数据来源
├── api/                    # JSON 数据接口层
│   ├── index.json / stats.json / data.json
│   ├── cities/<adcode>.json
│   ├── provinces/<省>.json
│   ├── food/top.json · districts/top.json
├── md/<省>/<市>.md         # Markdown 档案副本
└── README.html             # 本页

fun.worldstip.com 部署（Cloudflare Pages）

  • 构建命令：留空（纯静态）；输出目录：site。
  • DNS：fun CNAME 到 Cloudflare Pages 域名，橙色云 proxied。
  • 缓存：/api/*.json 与 /md/*.md 设 Cache-Control: public, max-age=86400；HTML 走默认。
  • 备选：GitHub Pages（本仓库 /docs 或根目录 + Actions）、Netlify Drop、任意 Nginx。

GitHub 备份

  • 仓库：MrdT-BitsNote/fun（public）。
  • 纳入版本管理：site/（网站 + JSON/MD 数据接口）与 data/（md 档案源）。
  • 不入库：.cache/（高德采集缓存，162MB 级）。

重新生成

python tools/build_api.py        # md 档案 → JSON 数据层（site/api + site/md）
python tools/build_fun_site.py  # JSON → 网站（site/*.html + assets）
python tools/validate_data.py   # C1–C10 数据校验
