API

数据接口

全站数据以 JSON + Markdown 双格式开放，供自有 skill 或第三方 agent 直接调用，无需爬虫。

端点格式说明
/api/index.jsonJSON全国总索引：省 → 市 → 轻量 meta + 商圈评级统计
/api/stats.jsonJSON全站统计：城市数、POI 数、评级分布、数据源
/api/cities/index.jsonJSON城市轻索引数组（含页面 / JSON / MD 三地址）
/api/cities/<adcode>.jsonJSON城市全量结构化数据：商圈档案与详情、美食、休闲、儿童、商场、特产、酒店、关联
/api/provinces/<省>.jsonJSON省级汇总：城市列表 + 聚合统计
/api/food/top.jsonJSON全国美食榜（按评分，含图片与城市跳转地址）
/api/districts/top.jsonJSON全国商圈 S/A 级榜单（按关联美食数）
/md/<省>/<市>.mdMarkdown城市档案原文，skill 直读；与 JSON 同源同值
/data.jsonJSON兼容旧版轻量总索引
调用示例 
# 全国索引
curl -s https://fun.worldstip.com/api/index.json

# 岳阳全量数据（adcode 430600）
curl -s https://fun.worldstip.com/api/cities/430600.json

# 全国美食榜前 10
curl -s https://fun.worldstip.com/api/food/top.json | jq '.items[:10]'

# 城市档案 Markdown 原文
curl -s https://fun.worldstip.com/md/湖南省/岳阳市.md
  • 所有端点只读、无鉴权、无速率限制，允许 CDN 缓存。
  • 字段口径与接口文档一致；JSON 与 MD 由同一数据层生成，可交叉校验。
  • 评分/人均为高德快照，采集时间见各城市档案头部。
