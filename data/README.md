## ⚠️ 当前阻塞：高德 key IP 白名单

本批建库进行到 51 城（34,426 POI）时，高德 key 开始对所有城市返回
`INVALID_USER_IP`（infocode 10005）——这是 key 配置的 **IP 白名单**
限制，不是限流、不会自愈、重试无效。剩余约 339 城未采集。

**解除步骤**：登录高德开放平台控制台 → 应用管理 → 该 key 的
「IP 白名单」设置 → 加入当前出口 IP（或清空白名单）→
重新跑 `python tools/amap_collect.py --all --budget <上限>`。
脚本会跳过已采城市（progress.json），只补未采部分。

## 校对入口

1. 打开任一城市 md 的 **§8 校对待办**，那是机器已识别的问题清单。
2. 全量机器校验：`python tools/validate_data.py`（8 项规则，含表格列数、粗体配对、悬空引用）。
3. 补采单城：`python tools/amap_collect.py --city XX市`，**注意预算**（单城约 48–50 请求）。
4. 重渲染：`python tools/render_md.py --all`。

## 数据口径与已知边界

- **评分**取高德 `biz_ext.rating`，无人工干预；无评分者一律 ⚠️，不做无据推荐。
- **人均**取高德 `biz_ext.cost`，单位元，可能滞后于实际涨价。
- **图片**取高德店铺图 URL，仅供校对时肉眼确认门店真实性。
- **苍蝇馆不做无据判定**：小店语义 + 评分区间双条件，宁可漏列也不编造。
- **关联为机器初判**：仅靠距离的关联必须人工确认，防止景区边界、跨街区误配。
- **撤柜风险**：§6 场内儿童游乐的撤柜率高，去之前需二次确认营业状态。
